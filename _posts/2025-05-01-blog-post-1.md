The Obsolete Material Project checks whether our library resources are the last copies in the country. If so, we need to retain them according to regulations. This project uses the Trove API to automate the process.

Problem
======
Part of the obsolete materials review process is to identify whether a library resource is the last copy in Australia. If it is, the item is retained. However, checking this manually can be a mundane and time-consuming task. Although staff can search Trove’s catalogue directly or use a library management system widget, reviewing titles one by one is inefficient and impractical at scale.

Method
======
With the availability of the Trove API, I developed an automated way to identify whether a title is held by only one library in Australia. This was done by retrieving each title through the Trove API and checking the number of search results and the holding library codes returned.

This process mirrors what would normally be done manually: confirming that a title exists in Trove and verifying whether it is held by a single library. When the search result count equals one and only one holding library code is returned, the item is identified as a last copy in Australia. This approach ensures accuracy while significantly reducing manual checking

With this in mind, I created a Python script that replicate the steps above. Instead of filtering the results within the script , I chose to output all retrieved data and perform the filtering in Excel. This approach make sure that I'm not missing out on any relevant information and allowed for greater flexibility in reviewing results.

Impact
======
I’ve successfully identified over 300 titles and provided recommendation to keep or withdrawal and ensure the research currency of our Library collections
